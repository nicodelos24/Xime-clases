# Ui

Tokens Aurora y componentes compartidos; tema claro/oscuro del sistema. tokens.css es la referencia CSS de diseño; src/tokens.ts su equivalente nativo.

La verificación de tipos corre con `npx tsc --noEmit -p packages/ui/tsconfig.json` desde `v2/`. La barrera de imports entre módulos está en `v2/test/fronteras.test.ts`.
